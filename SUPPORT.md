# Support

RunOnMine is pre-release software. Start with the [official website](https://runonmine.github.io/), the [README](README.md), and the [documentation index](docs/README.md).

## Bugs and reproducible defects

Use GitHub Issues for non-sensitive, reproducible product defects. Include the
RunOnMine version or commit, operating system, expected behavior, actual
behavior, and the smallest reproduction that demonstrates the problem. Remove
credentials, private filesystem paths, cookies, personal data, secret connector
URLs, and raw audit payloads before posting.

## Security issues

Do not open a public issue for a vulnerability. Use the repository's GitHub
private vulnerability reporting flow described in [SECURITY.md](SECURITY.md).
If private vulnerability reporting is temporarily unavailable, do not publish
exploit details or secrets while repository owners restore the private channel.

## Installation and usage

For installation, connector, permission, and recovery questions, read:

- [secure onboarding](docs/onboarding.md)
- [connection modes](docs/connections.md)
- [macOS](docs/platforms/macos.md), [Linux/VPS](docs/platforms/linux.md), and [Windows](docs/platforms/windows.md)
- [troubleshooting](docs/troubleshooting.md)

RunOnMine does not provide a promise of production support or compatibility
stability during the beta period.
