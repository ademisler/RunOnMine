# Product artwork

`runonmine.svg` is the editable source of truth for the RunOnMine monogram. The
runtime icon, Linux PNG, Windows ICO/installer artwork, and macOS ICNS must keep
the same dark-green background and mint R mark.

The checked-in macOS ICNS was generated on macOS from a 1024 px Quick Look render
of the SVG, with the standard 16, 32, 128, 256, 512, and 1024 pixel iconset
entries, then compiled with `iconutil -c icns`.

Artwork must not contain machine names, user paths, tokens, audit records, or
third-party trademarks.
